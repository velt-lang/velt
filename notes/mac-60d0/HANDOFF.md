## How to measure

- **arm64 (the VM, `orb -m velt-prof`)**: `notes/mac-60d0/sleep/vm-cg.sh`. Edit its `HEAD`/`BASE`
  paths if worktrees move. BASE = a worktree checked out at the main the PR is merged with
  (`branches/main-base`, detached; move it with `git -C branches/main-base checkout --detach <sha>`).
  - `orb -m velt-prof bash vm-cg.sh build`: a release velt + runtime from HEAD's source, in the VM.
  - `orb -m velt-prof env AB_STD=<std dir> bash vm-cg.sh ab <rows...>`: base std vs that std, T1
    and T4, in basis points (cachegrind instructions, one codegen unit, same compiler).
  - `... rep <row> <threads> <runs>`: interleaved repeats, for bimodal rows (pingpong_colocated,
    race_select and spawn_many at T4 are bimodal in base and head alike).
  - `... profab <row>` (`TH=4` for 4 threads): per-function difference. `... annot <row>`: full
    line-annotated output into `branches/notes-3097/ann/`.
  - `... clean`, then `orb -m velt-prof bash -c 'rm -rf ~/r3273'`, after every turn.
- **Mac stress (std-only changes need no build)**: run sleep-home's `target/debug/velt` with
  `VELT_STD=<std>`. `sleep/stress.sh`, `sleep/hang.sh` (loaded loops, 25 s cap, `sample` on a
  hang), `sleep/pinned.sh` (pinned probes, with a "broken" std from `break.py` that must ICE),
  `sleep/probe1.sh`. The test file `crates/veltc/tests/std_scheduler_sleep_handed.rs` is
  generated by `sleep/mktest.py` from the `.velt` probes (run `cargo fmt -p veltc` after).
- **#3322**: `parked/run.sh` (golden at 1/4/8/rescue), `parked/breaks.sh` with `mut.py`
  (gate, nested, joinparked, handlate must all fail), `parked/check.sh` (suites with its std).
- **#3202**: `spare/spare.sh` (Mac, never reproduced there); Windows runs by the coordinator.

Pitfalls learned here:
- `m.st` stores aren't paired by LLVM, so field layout changes don't save instructions.
- An exported module `const` holding an `Atomic` reads 0 from other modules: use a function.
- Main's `@inline` is a hint since #3230; spell `@inline("always")`.
- The push hook's std-lint needs a runtime in the worktree's target; without one, run
  `velt run scripts/std-lint/main.velt -- --base origin/main <files>` with another build and
  push with `--no-verify`.
